# ☕️ 시타벅스
### 이 프로젝트는 도메인 단위의 설계를 중점으로 두었습니다. 
_일상에서 밀접하게 겪을 수 있는 카페를 타깃으로 하였으며, 카페 안에서 벌어지는 일 혹은 사물을 모듈화 하여 프로젝트를 구성했습니다._

### 이 프로젝트는 POJO 기반 도메인 설계 및 비즈니스 로직 구성을 핵심으로 하여 프레임워크 및 외부 구현체에 제한 받지 않는 것을 목표로 했습니다.
_설계 이후 Spring 프레임워크를 활용한 백오피스 혹은 매장 포스에 사용될 API 제공을 목표로 합니다._

> 프로젝트 진행도 15%

> 브랜치 컨벤션 설명

## 프로젝트 설계

---

### 도메인 분리 (6개)
* 재고
* 주문
* 결제
* 정산 & 통계
* 인증
* 제조

## 프로젝트 구조 및 아키텍처

---

### 패키지 구조
* api (도메인에 접근할 수 있는 인터페이스)
* service (도메인을 사용하여 비즈니스 로직 구현)
* domain (도메인 내부 핵심 규칙 및 도메인 로직 수행)
  * model (도메인을 구성하는 현실세계의 객체화)
  * modelRepository (도메인 모델의 영속화를 위한 인터페이스)
* infra (외부와 맞닿아있는 인터페이스의 구현체)
